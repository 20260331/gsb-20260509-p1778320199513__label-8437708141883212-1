# 打飞机游戏

一个基于HTML5 Canvas的经典打飞机网页游戏。

## 游戏简介

这是一个简单而有趣的打飞机游戏，玩家控制一架飞机，通过射击来消灭不断出现的敌人飞机，获得分数。游戏具有完整的得分系统、生命值系统和游戏结束机制。

## 如何运行

### 方式一：直接打开
1. 克隆或下载项目到本地
2. 在浏览器中打开 `frontend/index.html` 文件即可开始游戏
3. 无需安装任何依赖或配置环境

### 方式二：使用Docker Compose
1. 克隆或下载项目到本地
2. 确保已安装Docker和Docker Compose
3. 在项目根目录执行 `docker compose up`
4. 在浏览器中访问 `http://localhost:3000` 开始游戏

## 游戏操作

- **方向键**：控制飞机移动
  - 左箭头：向左移动
  - 右箭头：向右移动
  - 上箭头：向上移动
  - 下箭头：向下移动
- **空格键**：发射子弹

## 游戏界面

- 左上角：当前得分
- 右上角：剩余生命值
- 中间：游戏画布
- 下方：控制按钮
  - 开始游戏：开始新游戏
  - 暂停游戏：暂停/继续游戏
  - 重新开始：重置游戏

## 游戏规则

1. 玩家初始有3条生命值
2. 击中敌人飞机获得10分
3. 玩家飞机与敌人飞机碰撞，扣除1条生命值
4. 敌人飞机到达屏幕底部，扣除1条生命值
5. 当生命值为0时，游戏结束

## 技术栈

- HTML5：页面结构
